CrossBlink Flasher

Install CrossBlink on your reTerminal Sticky and copy Cert Study Hub tracks to it, straight from this page over a USB cable. Nothing to install, and your SD card, books, settings and study progress are left alone.

This page needs Web Serial, which Chrome and Edge on a computer have (Safari and Firefox do not). Open this page in Chrome to continue.

1Plug in the Sticky

Connect the Sticky to this computer with a USB-C data cable and turn it on. When you press a button below, Chrome asks which device to use: pick the one named USB JTAG/serial debug unit (or similar).

2Install firmware

The new firmware goes into the Sticky's spare app slot, then the Sticky is told to start from it. The firmware running now is not touched until the new one is fully written and checked, so a dropped cable just leaves the old version in place.

3Send Cert Study Hub tracks
